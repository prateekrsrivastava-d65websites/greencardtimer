# Green Card Timer

An original, free public-data tool. No accounts, paywalls, payment processor, application analytics, or backend database. Priority-date calculations and salary searches run in the browser; preferences stay in local storage.

## Run

Requires Node 22+ and Python 3. Python uses only its standard library.

```sh
npm ci
npm run ingest:dol
npm run dev
```

`npm test` checks cutoff rules, trend calculations, data parsing, salary search, and build metadata. `npm run build` builds the UI using existing data. `npm run build:data` first ingests the full configured DOL source, then builds everything into `dist/`. `npm run preview` previews that output.

## Deploy

Push this directory as the repository root. Connect the repository through [Cloudflare Pages Git integration](https://developers.cloudflare.com/pages/configuration/git-integration/); this path does not require a deployment token in GitHub Actions.

- Build command: `npm run build:data`
- Output directory: `dist`
- Production branch: `main`
- Build image: v3, with `NODE_VERSION=22.16.0` and `PYTHON_VERSION=3.13.3`
- Set `SITE_URL` to the final HTTPS origin, such as your actual custom domain, to enable canonical links, `robots.txt`, and `sitemap.xml`. Without it, none of those domain-specific files or tags are generated.

The [current build image includes Python](https://developers.cloudflare.com/pages/configuration/build-image/). Attach the custom domain through the Cloudflare dashboard after the first successful deployment. This is a static app: no KV, D1, R2, Worker, paid API, or secrets are needed for serving it. Free-tier limits still apply; a domain registration is separate.

CI tests and builds the small tracked source. Large salary outputs are deliberately ignored by Git and regenerated by the Cloudflare build. The configured FY2026 Q3 workbook is approximately 252 MB compressed. A cached full-source run measured 96 seconds and about 550 MiB peak RAM locally; remote download/build performance is not yet measured. It produced 391,764 certified H-1B cases, a 4.65 MB index, and 256 shards totaling 75 MB, each below 3 MB. The workbook is streamed, not fully expanded into memory. `.cache/dol` avoids repeated local downloads, but persistence of that directory in hosted builds is not assumed. A source/download/parser failure fails the build, leaving the last successful deployment intact.

## Data & Updates

- Visa bulletins: [official Department of State monthly tables](https://travel.state.gov/content/travel/en/legal/visa-law0/visa-bulletin.html), with 25 sourced months from October 2024 through October 2026 in `public/data/bulletins.json`. `C` and `U` are preserved. A dated cutoff requires a priority date strictly earlier than the cutoff.
- Filing chart: verify [USCIS's monthly chart choice](https://www.uscis.gov/visabulletininfo) before any I-485 filing. The app marks the choice unknown instead of assuming Dates for Filing is permitted. A current cutoff does not mean an application will be approved.
- Salary disclosures: [DOL OFLC performance data](https://www.dol.gov/agencies/eta/foreign-labor/performance). The configured quarter is cumulative, not an entire historical database. Included records are certified H-1B LCAs with annualized wages from $5,000 through $1,000,000; duplicate case numbers, other statuses/classes, and missing or unsupported wage units are excluded. These wages are disclosed offers, not evidence of visa issuance, individual earnings, or green-card sponsorship.
- Scenarios: source code and `public/data/model.json` describe rolling six-month historical cutoff rates. These are illustrative pace scenarios, not queue estimates, probability intervals, or guaranteed dates. No inaccessible USCIS inventory is invented.

The daily bulletin workflow runs at 12:37 UTC and supports manual dispatch. It fetches official HTML, validates both employment tables and every tracked cell, rejects missing months or rollback, then tests and builds before committing only changed bulletin/model files. Unchanged source tables do not create timestamp-only commits. GitHub schedules may be delayed, and a public repository's inactive schedules can be disabled by GitHub.

Direct access to DOS and USCIS returned HTTP 403 during local verification. Automated access from a real GitHub runner is not yet proven. Fetch errors and unexpected table formats fail closed without replacing the tracked dataset. If blocked, review the official bulletin manually, update the structured JSON with its source URL and verification date, then run:

```sh
npm run refresh:bulletins -- --offline
npm test
npm run build
```

Review and commit both data files. Never substitute an empty response or an invented queue. For a new DOL release, verify the official disclosure URL, update the configured source, and rebuild. Do not combine cumulative quarters from the same fiscal year. `npm run ingest:dol -- --refresh` re-downloads corrected files with the same name.

## Build Details

The postbuild step creates useful initial route HTML and distinct metadata for the estimator, visa bulletin, salary data, methodology, and privacy pages. Latest sourced tables and essential rules remain readable before JavaScript loads; the client then replaces the main content with the interactive tool. It uses Lucide's icon data for the favicon. Security headers apply to every static response; JSON refreshes after five minutes, and only exact content-hashed build assets receive one-year immutable caching. No third-party scripts or runtime data services are required.
